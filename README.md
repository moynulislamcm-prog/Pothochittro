# পথচিত্র

বাংলাদেশের ৬৪ জেলার মানচিত্র, গন্তব্য আর নিজের ভ্রমণের হিসাব — লাইভ লোকেশন,
ঘোরা জেলা মার্ক করা, আর দূরত্ব মাপা এক জায়গায়।

- **সাইট**: React + Vite + Leaflet
- **ব্যাকএন্ড**: Supabase (Postgres + Auth + Row Level Security)
- **এডমিন প্যানেল**: `/admin` — আলাদা লেআউট, আলাদা লগইন গেট

---

## কী কী আছে

| পেজ | কী করে |
|---|---|
| `/` | হিরো + খোঁজ, মানচিত্র (লাইভ লোকেশনসহ), আর «আমি যে জেলাগুলো ঘুরেছি» |
| `/districts` | ৬৪ জেলা — বিভাগ অনুযায়ী, খোঁজ ও ফিল্টার, ক্লিক করে মার্ক |
| `/districts/:id` | এক জেলার নির্দেশিকা — গন্তব্য, উপজেলা, দূরত্ব |
| `/places` | সব গন্তব্য — ধরন/জেলা/উপজেলা ফিল্টার |
| `/distance` | দুই বিন্দুর দূরত্ব — সরলরেখা + ঐচ্ছিক সড়কপথ |
| `/my-travel` | ঘোরা জেলা, যেতে চাই, নোট, ব্যাকআপ |
| `/admin` | এডমিন প্যানেল |

## চালানো

```bash
cd web
npm install
npm run dev          # http://localhost:5173
```

প্রোডাকশন বিল্ড:

```bash
cd web
npm run build        # আউটপুট web/dist
npm run preview
```

### এনভায়রনমেন্ট ভেরিয়েবল (ঐচ্ছিক)

ডিফল্টে সাইটটি এই Supabase প্রজেক্টে যুক্ত: `oxziyvshobedekqobyyo`।
অন্য প্রজেক্টে নিতে চাইলে `web/.env` ফাইলে দিন:

```env
VITE_SUPABASE_URL=https://<আপনার-প্রজেক্ট>.supabase.co
VITE_SUPABASE_ANON_KEY=<publishable key>
```

> publishable/anon কী পাবলিক — ব্রাউজারে থাকা নিরাপদ। আসল নিরাপত্তা
> Row Level Security নীতিতে (`supabase/schema.sql`)।

ব্যাকএন্ড ছাড়া শুধু ব্রাউজারে চালাতে চাইলে:

```env
VITE_PATHCHITRO_STANDALONE=true
```

## ব্যাকএন্ড সেটআপ

### ১. স্কিমা

`supabase/schema.sql` ফাইলটি Supabase SQL Editor-এ চালান (বা `supabase db push`)।
এতে তৈরি হয়:

| টেবিল | কী রাখে |
|---|---|
| `pc_divisions` | ৮ বিভাগ |
| `pc_districts` | ৬৪ জেলা |
| `pc_upazilas` | ৪৯২ উপজেলা |
| `pc_places` | ২১৫ গন্তব্য |
| `pc_boundaries` | জেলার GeoJSON সীমানা |
| `pc_profiles` | ব্যবহারকারী ও ভূমিকা (`traveler` / `admin`) |
| `pc_visited` | কোন ব্যবহারকারী কোন জেলা ঘুরেছেন / যেতে চান |
| `pc_place_marks` | গন্তব্যভিত্তিক মার্ক |
| `pc_settings` | সাইট সেটিংস ও এডমিন ইমেইল তালিকা |

> হোটেল, খাবার, দাম বা যাতায়াত ভাড়ার কোনো টেবিল নেই — শুধু দূরত্ব রাখা হয়েছে,
> সেটিও ক্লায়েন্ট সাইডে হিসাব হয়।

### ২. ডেটা ভরা

এডমিন প্যানেলে লগইন করে **ইমপোর্ট / এক্সপোর্ট → সিড চালান** চাপুন।
বান্ডিলের পরিষ্কার ডেটা (`web/public/data/`) এক ক্লিকে ডেটাবেসে উঠে যাবে।
দুইবার চাপলেও ডুপ্লিকেট হবে না (upsert)।

### ৩. এডমিন অ্যাক্সেস

প্রথমবার: `/admin` → নতুন অ্যাকাউন্ট খুলুন → **এডমিন দাবি করুন**।
সিস্টেমে একজনও এডমিন না থাকলে এই বোতাম কাজ করে; এরপর নিরাপত্তার জন্য বন্ধ হয়ে যায়।

পরে নতুন এডমিন যোগ করতে: **এডমিন → সেটিংস → এডমিন তালিকা**য় ইমেইল যোগ করুন,
অথবা **ব্যবহারকারী** পেজ থেকে ভূমিকা বদলান।

## ডেটা তৈরির পাইপলাইন

পুরনো সাইটের একক HTML ফাইল (`legacy/pathchitro-website-v1.html`) থেকে ডেটা বের করে
পরিষ্কার করা হয়:

```bash
node scripts/build-data.mjs
```

এটি যা করে:

1. এমবেডেড JSON ডেটা বের করে
2. `scripts/corrections.json` অনুযায়ী বানান সংশোধন করে
3. হোটেল / খাবার / দাম / যাতায়াত ভাড়ার সব রেকর্ড বাদ দেয়
4. উৎস ও অ্যাট্রিবিউশন তথ্য সাইটের ডেটা থেকে সরায়
5. ছবিগুলো আলাদা `.webp` ফাইলে লেখে
6. প্রতিবেদন তৈরি করে

আউটপুট:

| ফাইল | কী |
|---|---|
| `web/public/data/*.json` | সাইটের ডেটা (সিড + অফলাইন ফলব্যাক) |
| `web/public/data/boundaries.geojson` | জেলার সীমানা |
| `web/public/images/*.webp` | গন্তব্যের ছবি |
| `data/SPELLING_FIXES.md` | কোন নাম কী থেকে কী হয়েছে |
| `data/COORDINATE_REVIEW.md` | যেসব স্থানাঙ্ক খতিয়ে দেখা দরকার |
| `data/IMAGE_LICENSES.md` | ছবির লাইসেন্স রেকর্ড (সাইটে দেখানো হয় না) |

নতুন নাম ঠিক করতে `scripts/corrections.json`-এ যোগ করে আবার স্ক্রিপ্ট চালান।

> **ইউনিকোড নোট**: বাংলায় কিছু অক্ষর দুইভাবে এনকোড হতে পারে (যেমন `ড়` = U+09DC
> অথবা U+09A1 + U+09BC)। পাইপলাইন সব তুলনা NFC-তে স্বাভাবিকীকরণ করে, না হলে
> অনেক সংশোধন ধরাই পড়ত না।

## ভ্রমণতালিকা কীভাবে কাজ করে

- **গেস্ট**: সব তথ্য `localStorage`-এ থাকে, কোনো অ্যাকাউন্ট লাগে না।
- **লগইন করলে**: ব্রাউজারের তালিকা অ্যাকাউন্টের তালিকার সাথে মার্জ হয়
  (নতুন তথ্য পুরনোটা মুছে দেয় না), তারপর দুই দিকেই সমান থাকে।
- ইন্টারনেট না থাকলে কাজ ব্রাউজারেই চলতে থাকে; সংযোগ ফিরলে
  **আমার ভ্রমণ → সার্ভারে সংরক্ষণ** চাপলে মিলে যায়।
- যেকোনো সময় JSON ব্যাকআপ ডাউনলোড করা যায়।

## নোট

- **দূরত্ব**: সরলরেখার দূরত্ব Haversine দিয়ে হিসাব হয়। «সড়কপথের দূরত্ব»
  বোতাম একটি পাবলিক রাউটিং সার্ভার ব্যবহার করে — সেটি না চললে সরলরেখার
  দূরত্বই দেখানো হয়। নদী ও পাহাড়ে প্রকৃত পথ অনেক ভিন্ন হতে পারে।
- **মানচিত্রের টাইল**: বাইরের টাইল সার্ভার থেকে আসে, তাই মানচিত্রের কোণায়
  প্রদানকারীর ছোট একটি কৃতিত্ব লাইন থাকে। এটি এডমিন → সেটিংস থেকে বন্ধ করা যায়।
  বাকি সব তথ্যসূত্র/লাইসেন্স অংশ সাইট থেকে সরানো হয়েছে।
- **ছবি**: `legacy/` ফাইল থেকে বের করা; একটি ছবি (কুসুম্বা মসজিদ) মূল ফাইলে
  শুধু পাথ-রেফারেন্স ছিল, তাই সেটির ছবি পাওয়া যায়নি।
